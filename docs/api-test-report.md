# 4. POST `/chat`

## Valid Request

### Request

```http
POST /chat
```

```json
{
    "message": "What is FastAPI?"
}
```

## Expected Result

The API should return HTTP `200`.

## Expected Response

```json
{
    "answer": "This is a placeholder answer to your message: What is FastAPI?",
    "model": "placeholder"
}
```

The answer is generated by placeholder logic at this stage.

## Validation Rules

The `message` field:

* is required
* must be a string
* must contain at least 1 character
* must contain no more than 2000 characters

## Invalid Request

```json
{
    "message": ""
}
```

## Expected Result

HTTP `422 Unprocessable Entity`.

The request is rejected because the `message` field has a minimum length of 1 character.

## Automated Tests

The endpoint is tested using pytest and HTTPX in:

```text
tests/test_chat.py
```

The tests cover:

1. A valid chat request
2. An invalid chat request

Expected results:

```text
test_chat PASSED
test_chat_invalid_message PASSED
```

# 5. POST `/quiz`

## Valid Request

### Request

```http
POST /quiz
```

```json
{
    "topic": "Python",
    "number_of_questions": 3
}
```

## Expected Result

The API should return HTTP `200`.

## Expected Response

```json
{
    "topic": "Python",
    "number_of_questions": 3,
    "questions": [
        {
            "id": 1,
            "question": "What is an important concept in Python?",
            "options": [
                "Concept A",
                "Concept B",
                "Concept C",
                "Concept D"
            ]
        }
    ]
}
```

The response should contain the requested number of questions.

## Validation Rules

The `topic` field:

* is required
* must be a string
* minimum length: 2 characters
* maximum length: 100 characters

The `number_of_questions` field:

* is required
* must be an integer
* minimum value: 1
* maximum value: 20

## Invalid Request: Too Few Questions

```json
{
    "topic": "Python",
    "number_of_questions": 0
}
```

## Expected Result

HTTP `422 Unprocessable Entity`.

The request is rejected because `number_of_questions` must be at least `1`.

## Invalid Request: Too Many Questions

```json
{
    "topic": "Python",
    "number_of_questions": 21
}
```

## Expected Result

HTTP `422 Unprocessable Entity`.

The request is rejected because `number_of_questions` cannot be greater than `20`.

# 7. Validation Error Format

FastAPI automatically returns a structured validation error when a request does not satisfy its Pydantic model.

For example, sending:

```json
{
    "message": ""
}
```

to `/chat` produces a response similar to:

```json
{
    "detail": [
        {
            "type": "string_too_short",
            "loc": [
                "body",
                "message"
            ],
            "msg": "String should have at least 1 character",
            "input": ""
        }
    ]
}
```

The exact error message can vary slightly depending on the installed Pydantic version.

The important information is:

* HTTP status: `422`
* location: request body
* field: `message`
* validation rule: minimum length
